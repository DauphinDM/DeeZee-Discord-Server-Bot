# Offline phishing blocklist -- the fallback when the Safe Browsing API is
# unavailable or no key is configured.
#
# Matched as suffixes, same as trusted_domains.txt. Anything here is treated as
# a confirmed threat without a lookup.
#
# This list covers the patterns that actually reach Discord servers: fake Nitro
# giveaways, Steam trade scams, and typosquats of discord.com. It is not a
# replacement for the API -- new phishing domains appear daily and a static file
# cannot keep up. It exists so that turning the API off degrades the scanner
# rather than disabling it.
#
# Maintenance: add a domain here when a scam gets through. Remove nothing that
# was ever malicious -- these domains get re-registered.
