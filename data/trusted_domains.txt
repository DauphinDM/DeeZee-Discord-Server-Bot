# Bundled trusted-domain list -- tier 1 of ?scanlinks.
#
# A URL whose domain appears here is allowed with no lookup of any kind. That is
# the entire point: the Safe Browsing API only ever sees domains that nothing
# local could answer for, which keeps quota use and latency down.
#
# Entries are matched as suffixes, so "github.com" also covers
# "gist.github.com". "notgithub.com" does not match.
#
# Blank lines and anything after a # are ignored.
#
# Per-guild additions live in the trusted_domains table (?scanlinks trust) and
# are checked as tier 2. Edit this file only for domains that should be trusted
# everywhere.
